# Keyword → page map (English and Arabic)

**Status of every phrase below: *suggestion to validate*, not researched.** No search volumes or difficulty scores are shown because none were measured.
Validate with Search Console *Performance → Queries* (after 4–8 weeks) and Google Keyword Planner (free with a Google Ads account, no spend required), then update this table.
Each intent maps to **one** page so pages do not compete. City names appear only where they are true and useful (Al Khobar = your location; Eastern Province / Saudi Arabia = where you supply).

## When to add another page
Add a page only if (1) the intent is not already owned above, (2) it holds content that is not on another page, and (3) you can back it with real catalogue data (e.g. a "Grooved couplings — rigid vs flexible" guide). City-only pages fail rule 2.
