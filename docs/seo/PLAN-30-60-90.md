# 30 / 60 / 90-day plan

Priorities are ordered by effect on **qualified enquiries**, not by tricks. Outcomes (impressions, clicks, enquiries) will only be known from Search Console and your own enquiry log.

## Days 1–30 — get found and measured
1. Run migrations 0010, 0011, 0012, redeploy, confirm `NEXT_PUBLIC_SITE_URL=https://www.kanzcorner.com` in Hostinger.
2. Verify Search Console, submit `sitemap.xml`, request indexing for home, one category, one product, Contact.
3. Create and verify the Google Business Profile (checklist) — highest local impact, free.
4. Publish **real products** with SKUs/sizes/specs in your priority categories (grooved fittings first, then pipes, fittings/flanges, valves). Empty categories are deliberately kept out of search until they have products.
5. For each published product: short description (what it is, material, sizes, standard), datasheet if you have one, 1–3 real photos with alt text (English and Arabic), Arabic name.
6. Enter opening hours, Arabic address, and review the generated titles in the SEO tab preview.
7. Test the site on real phones in Arabic and English; send a test quote and a WhatsApp enquiry.
8. Check Admin → Reports weekly: product views, WhatsApp/phone clicks, datasheet downloads, RFQs.

## Days 31–60 — deepen the pages that matter
1. In Search Console → Performance, list the real queries/pages. Update the keyword map; rewrite titles/descriptions of pages with impressions but few clicks.
2. Write/refine buying guides and category intros for your top 4 categories using your real expertise (what you are asked on the phone). Add 1–2 practical guides as new pages only if they answer a distinct question (e.g. rigid vs flexible grooved couplings; choosing flange class).
3. Add verified certifications/MTC documents per product (Admin → Certifications) where you really hold them; show them on the Quality page.
4. Replace low-resolution catalogue crops with real photos; check image sizes.
5. Review Arabic wording of top pages with a native reviewer (terminology: محابس/صمامات, وصلات, فلنجات).
6. Ask satisfied customers for genuine Google reviews; reply to every review.

## Days 61–90 — extend and earn trust
1. Add products and variants steadily; unpublished/empty categories stay hidden from search automatically.
2. If a real regional offer exists (e.g. an actual delivery arrangement for an area), publish one distinct page for it. Otherwise skip city pages.
3. Earn real links: supplier/manufacturer listings you are authorised for, industry directories, Saudi business directories, local chamber listings. No paid-link schemes.
4. Review Core Web Vitals in Search Console/PageSpeed with real traffic; fix the worst template, not every page.
5. Re-check indexing coverage: pages "Discovered/Crawled – not indexed" usually need more unique content, not more pages.
6. Decide on Google Analytics only if you need page-level funnel detail; it would require a cookie notice (not needed with the current first-party counting).

Technical SEO is finished once the items in README are deployed and verified; rankings and enquiries follow content quality, authority and competition over months.
